1. 타이타닉 문제는 왜 "생존/사망"을 맞추는 이진 분류 문제인가?

    타이타닉 문제에서 모델의 정답은 승객의 생존 또는 사망이기 때문에 두 개의 범주 중 하나를 선택하는 이진 분류 문제입니다.

2. 트리(Decision Tree) 하나만 쓰는 것보다 여러 개의 트리를 순서대로 만들어가는 방식(그래디언트 부스팅)이 왜 더 성능이 좋은가?

    결정트리를 하나만 사용하면 한 번의 학습으로 예측 규칙이 결정되기 때문에 트리가 잘못 예측한 부분이 그대로 최종 오차가 됩니다. 때문에 여러 트리를 순서대로 학습하면서 이전 트리가 틀린 부분을 다음 트리가 보완할 수 있는 그래디언트 부스팅이 더 성능이 좋습니다.

3. Validation 데이터는 왜 따로 필요한가? Train 데이터만으로 모델 성능을 확인하면 뭐가 문제인가?**

    Train데이터는 모델이 이미 학습할 때 사용한 데이터이기 때문에 이 데이터로 성능을 확인하게 되면 실제보다 더 높은 성능으로 평가될 수 있습니다. 또한 과적합 상태를 확인하기 위해서도 학습에 사용되지 않은 Validation 데이터를 사용해 평가해야 합니다.

4. Early Stopping은 왜 쓰는가? 계속 학습만 시키면 안 되는 이유는?

    모델이 처음 학습을 반복할 때는 데이터의 규칙을 학습하면서 성능이 좋아지지만 너무 오래 학습하면 규칙뿐만 아니라 데이터를 외우게 되면서 과적합이 발생할 수 있습니다. 이때 Early Stopping을 사용해서 성능이 일정 횟수동안 개선되지 않으면 학습을 중단하여 과적합을 줄이고 불필요한 학습 시간도 줄일 수 있습니다.

5. 모델 성능을 확인할 때 정확도(Accuracy) 대신 Logloss를 쓰는 이유는 무엇인가?

    정확도는 0,1로 예측 결과를 변환한 후에 정답 여부만 평가하기 떄문에 모델이 예측을 얼마나 확신했는지는 평가하지 못합니다. 반면 Longloss는 예측 확률 자체를 평가하고 틀린 결과를 확신할수록 더 큰 손실을 부여하기 때문에 모델의 확률 예측 성능을 정확도보다도 더 자세히 평가할 수 있습니다.

6. 모델이 0/1이 아니라 확률(예: 0.73)로 예측 결과를 주는 이유는 무엇인가?

    확률로 예측 결과를 주면 모델이 예측을 얼마나 확신하는지를 알 수 있고 확률에 따라 0,1을 나누는 기준도 조정할 수 있기 때문입니다.

7. 숫자로 바꾼 범주형 변수(Sex, Embarked 등)를 모델에게 "이건 범주형이야"라고 다시 알려주지 않으면 어떤 문제가 생기는가?

    모델에게 범주형 변수를 알려주지 않으면 이를 일반적인 숫자로 인식하면서 스스로 크기나 순서와 같은 관계를 부여할 수 있기 때문에 숫자가 단순히 범주 구분용인것을 알려주어야 합니다.

8. 하이퍼파라미터(사람이 정하는 값)와 파라미터(모델이 스스로 배우는 값)는 어떻게 다른가?

    하이퍼파라미터는 모델이 학습을 시작하기 전에 사람이 정하는 설정값으로 모델의 구조, 학습방식을 조절할 수 있습니다 반면 파라미터는 모델이 학습 데이터를 분석하면서 스스로 결정하는 값입니다.

9. K-Fold 교차검증을 한 번만 검증하는 것보다 더 믿을 수 있는 이유는 무엇인가?

    데이터를 한 번만 나누어 검증하면 어떤 데이터로 검증하는지에 따라 평가가 달라질 수 있습니다. 그러나 K-Fold 교차검증을 사용하면 여러 묶음으로 나눠진 데이터를 검증 데이터를 바꿔가며 여러 번 평가하기 때문에 한 번만 검증하는 것보다 더 안정적으로 모델의 실제 성능을 판단할 수 있습니다.

10. 모델 여러 개의 예측을 평균 내는 앙상블이 왜 모델 하나만 쓰는 것보다 더 안정적인가?

    같은 알고리즘을 사용해도 학습 데이터가 달라지면 모델마다 예측 결과가 조금씩 달라지며, 이때 어떤 모델은 극단적인 예측값을 낼 수 있습니다. 때문에 여러 모델의 예측 평균에선 이런 극단적인 예측이 최종 결과에 미치는 영향을 줄이고 모델마다 다른 오차들을 상쇄시킬 수 있기 때문에 모델 하나만 사용할 때 보다 더 안정적인 결과를 얻을 수 있습니다.
