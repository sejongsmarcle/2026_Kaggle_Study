# 과제 2
**1. 타이타닉 문제는 왜 "생존/사망"을 맞추는 이진 분류 문제인가?**

-> 그걸 목표로 잡았기 때문임. 당연하게도 다른 걸 맞추는 문제로 만들었다면 충분히 만들 수 있음. 해당하는 것에 대한 GT를 만들어 학습시키면 가능함.

-> '왜 생존 예측 문제를 회귀가 아니라 이진 분류로 다루는가' 같은 게 질문의 요지였다면, 생존은 삶 / 죽음 두 가지 동시에 성립할 수 없는 두 상태이므로 이진분류가 맞음.

**2. 트리(Decision Tree) 하나만 쓰는 것보다 여러 개의 트리를 순서대로 만들어가는 방식(그래디언트 부스팅)이 왜 더 성능이 좋은가?**

-> 그래디언트 부스팅은 여러 개의 트리를 순차적으로 학습하면서 이전 트리의 예측 오차를 다음 트리가 보완하는 방향으로 나아감. 따라서 여러 트리의 결과를 결합하여 하나의 트리보다 더 복잡한 패턴을 학습할 수 있고, 일반적으로 더 높은 예측 성능을 얻을 수 있음.


**3. Validation 데이터는 왜 따로 필요한가? Train 데이터만으로 모델 성능을 확인하면 뭐가 문제인가?**

-> 저번 주차에 Test / Train 데이터를 가르는 이유와 비슷함. Train 데이터는 이미 학습하면서 봤던 정보들이기 때문에 이를 통해 평가를 하면 과대평가 될 수 있기 때문.


**4. Early Stopping은 왜 쓰는가? 계속 학습만 시키면 안 되는 이유는?**

-> 계속 학습을 시키면 과적합이 일어날 수 있기 때문. 다른 이유로는 학습 시간을 조금이나마 줄이기 위함임.

**5. 모델 성능을 확인할 때 정확도(Accuracy) 대신 Logloss를 쓰는 이유는 무엇인가?**

-> 두 개가 담는 정보가 달라서. 정확도는 모델이 맞히다 / 틀렸는가를 다루는 정보고, logloss는 얼마나 그 정답 / 오답에 확신을 가졌느냐에 대한 confidence까지도 반영함. 따라서 좀 더 세밀한 확인이 가능.

**6. 모델이 0/1이 아니라 확률(예: 0.73)로 예측 결과를 주는 이유는 무엇인가?**

-> 모델은 각 클래스에 속할 가능성을 확률로 계산하기 때문임. 0/1로 구분하는 것은 뒤에 argmax 등을 이용해 하나의 카테고리로 묶는 것. 

**7. 숫자로 바꾼 범주형 변수(Sex, Embarked 등)를 모델에게 "이건 범주형이야"라고 다시 알려주지 않으면 어떤 문제가 생기는가?**

-> 모델이 그 값을 연속적인 숫자나 순서가 있는 값으로 해석할 수 있음. 따라서 실존하지 않는 어떤 관계를 임의로 학습해버릴 수도 있음.

**8. 하이퍼파라미터(사람이 정하는 값)와 파라미터(모델이 스스로 배우는 값)는 어떻게 다른가?**

-> 적힌 그대로 하이퍼파라미터는 사람이 정해주고, 파라미터는 모델이 학습을 통해 배워가는 값이다. 하이퍼파라미터는 따라서 모델의 구조나 학습 방법을 조절하기 위해. 파라미터는 모델의 가중치 같은 것.

**9. K-Fold 교차검증을 한 번만 검증하는 것보다 더 믿을 수 있는 이유는 무엇인가?**

-> 한 번만 검증하면 어떻게 나눴느냐에 따라 점수가 우연히 높거나 낮게 나올 수 있기 때문.

**10. 모델 여러 개의 예측을 평균 내는 앙상블이 왜 모델 하나만 쓰는 것보다 더 안정적인가?**

-> 모델이 서로 상호보완적인 역할을 할 수 있기 때문임. 여러 모델은 서로 다른 방식으로 학습하므로 예측 오류가 서로 다를 수 있음.
