회귀(Regression)와 분류(Classification)는 무엇이 다르며, 어떤 문제를 풀고 있는지는 무엇을 보고 판단할 수 있는가?\
회귀 = 연속적인 그래프(수치, 값)를 예측하고, 분류 = 정해진 범주를 예측한다.\
내가 예측하려는 값이 어떤 타입(수치, 범주)인지 확인하고 판단 할 수 있다.\
\
분류 모델에서 Accuracy가 높다고 해서 항상 좋은 모델이라고 할 수 없는 이유는 무엇인가?\
데이터의 한쪽 클래스가 훨씬 많은 경우를 예로 들어 설명해보자.\
라벨 0인 데이터가 99개 1인 데이터가 1개가 있을 때 모든 예측을 0이라고 하면 정확도가 99가 나오지만 label이 1인건 하나도 찾지 못한다.\
\
데이터를 StandardScaler 등의 방법으로 스케일링하는 이유는 무엇인가?\
모든 머신러닝 모델에서 스케일링이 똑같이 중요한지도 함께 설명해보자.\
각 변수마다 단위가 다르다 어떤 변수는 0~10 어떤 변수는 100 ~ 900의 범위의 값을 가질 수 있다. 이를 똑같은 스케일로 맞춰줘야 한다.\
트리기반의 모델은 스케일링의 영향을 크게 안 받는다.\
\
데이터 누수(Data Leakage)란 무엇이며, 데이터 누수가 발생하면 Validation 성능이 실제보다 높게 나올 수 있는 이유는 무엇인가?\
누수가 발생할 수 있는 상황도 한 가지 예를 들어보자.\
데이터 누수란 Train 데이터 이외에 데이터가 학습할 때 들어가는 상황을 말한다.\
예시 상황으로 검증 데이터가 학습에 이용되면 검증 점수가 실제보다 높게 나온다.\
\
파라미터(Parameter)와 하이퍼파라미터(Hyperparameter)는 어떻게 다른가?\
하이퍼파라미터 값을 바꾸면 모델의 성능이 달라질 수 있는 이유도 설명해보자.\
파라미터 : 모델이 학습을 통해 결정하는 값\
하이퍼파라미터 : 사람이 직접 결정해야하는 값\
예를 들어 하이퍼파라미터인 트리 깊이가 너무 작으면 데이터의 특징을 충분히 학습하지 못하고, 너무 크면 학습 데이터에 과적합할 수 있어 성능이 달라진다.\
\
Random Forest와 Gradient Boosting(XGBoost, LightGBM 등)은 모두 여러 Decision Tree를 사용하는데, 트리를 만드는 방식에는 어떤 차이가 있는가?\
Random Forest : 여러 트리를 독립적으로 학습하고 각 트리의 예측 비율로 결과를 도출한다.\
Gradient Boosting : 기존 모델의 오류를 줄이는 방향으로 트리를 순차적으로 연결하여 모델을 개선한다.\
\
GridSearchCV와 같은 하이퍼파라미터 탐색 방법을 사용하는 이유는 무엇인가?\
가능한 값을 무조건 많이 탐색하면 항상 더 좋은 모델을 찾을 수 있는지도 생각해보자.\
하이퍼파라미터는 변수가 너무 많아서 사람이 일일이 찾기 힘들다.\
값을 많이 탐색하면 계산량이 증가하고, 적절한 값을 못 찾을 수 있다.\
\
Train 또는 Validation에서는 성능이 좋았지만 실제 Test 데이터에서 성능이 크게 떨어졌다면 어떤 원인을 의심할 수 있는가?\
과적합, 데이터 누수, Train/Test 데이터 차이 등의 개념을 활용하여 설명해보자\
일반적인 상황보다 학습데이터에 과도하게 맞춰져 test 데이터에서 점수가 덜 나오는 과적합을 원인으로 의심할 수 있다.\
