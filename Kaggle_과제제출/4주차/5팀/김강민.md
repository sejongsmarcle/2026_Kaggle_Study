    model_lgb = lgb.train(lgbm_params,

                          early_stopping_rounds=20,
                          verbose_eval=10,
                         )

models.append(model_lgb)

1. 회귀(Regression)와 분류(Classification)는 무엇이 다르며, 어떤 문제를 풀고 있는지는 무엇을 보고 판단할 수 있는가?
- 회귀는 연속적인 수치를 예측하고, 분류는 이산적인 범주를 예측한다. 예측하려는 타겟 데이터의 타입이 수치형인지 범주형인지를 확인하여 어떤 문제인지 판단할 수 있다.

2. 분류 모델에서 Accuracy가 높다고 해서 항상 좋은 모델이라고 할 수 없는 이유는 무엇인가?
   데이터의 한쪽 클래스가 훨씬 많은 경우를 예로 들어 설명해보자.
- 전체 100중에 불량 데이터가 단 1이더라도 99퍼센트의 정확도가 나오기 때문이다.
  소수 클래스를 전혀 찾아내지 못해도 정확도가 높게 착시를 일으킬 수 있다.

3. 데이터를 StandardScaler 등의 방법으로 스케일링하는 이유는 무엇인가?
   모든 머신러닝 모델에서 스케일링이 똑같이 중요한지도 함께 설명해보자.
- 특성 간 단위 차이가 클 때, 특정 변수가 결과에 과도하게 영향을 미치는 것을 막는다.
  트리 기반 모델에서는 스케일링이 중요하지 않다.


4. 데이터 누수(Data Leakage)란 무엇이며, 데이터 누수가 발생하면 Validation 성능이 실제보다 높게 나올 수 있는 이유는 무엇인가?
   누수가 발생할 수 있는 상황도 한 가지 예를 들어보자.
- 실전에서는 알 수 없는 미래의 정보나 정답과 직결된 정보가 훈련 데이터에 섞여 들어가는 현상이다.
  모델이 패턴을 학습하지 않고 정답을 '암기'하기 때문에 검증 성능은 높게 나오게 된다.

5. 파라미터(Parameter)와 하이퍼파라미터(Hyperparameter)는 어떻게 다른가?
   하이퍼파라미터 값을 바꾸면 모델의 성능이 달라질 수 있는 이유도 설명해보자.
- 파라미터는 모델이 학습하여 스스로 찾아내는 가중치 값이다.
  하이퍼파라미터는 학습 전 사용자가 직접 설정해주는 값이다.
  모델의 복잡도나 학습 속도를 제어할 수 있다.

6. Random Forest와 Gradient Boosting(XGBoost, LightGBM 등)은 모두 여러 Decision Tree를 사용하는데, 트리를 만드는 방식에는 어떤 차이가 있는가?
   - 랜덤 포레스트는 여러 트리를 독집적으로 동시에 학습시켜 결과를 다수결로 합치는 방식이다.
     그래디언트 부스팅은 예측에 실패한 오차를 다음 트리가 순차적으로 보완하여 학습하는 방식이다.

7. GridSearchCV와 같은 하이퍼파라미터 탐색 방법을 사용하는 이유는 무엇인가?
   가능한 값을 무조건 많이 탐색하면 항상 더 좋은 모델을 찾을 수 있는지도 생각해보자.
   - 지정한 하이퍼파라미터 조합을 교차 검증하여 최적의 모델 설정을 체계적으로 찾기 위해 사용한다.
     무작정 늘리면 연산 시간만 크게낭비될 수 있다.

8. Train 또는 Validation에서는 성능이 좋았지만 실제 Test 데이터에서 성능이 크게 떨어졌다면 어떤 원인을 의심할 수 있는가?
   과적합, 데이터 누수, Train/Test 데이터 차이 등의 개념을 활용하여 설명해보자
   - 훈련 데이터의 노이즈까지 암기한 과적합 현상을 의심할 수 있다.
     훈련 단계에서 데이터 누수가 발생했거나 Train데이터와 Test 데이터간의 특성 차이가 클 떄 이러한 현상이 발생한다.
