## 2. 개념설명 문제(자신만의 해설 작성)
##### 회귀(Regression)와 분류(Classification)는 무엇이 다르며, 어떤 문제를 풀고 있는지는 무엇을 보고 판단할 수 있는가?
###### 둘의차이는 Target의 형태이다. 생존사망같은 0,1로 예측해야하는건 회귀. 주택값처럼 숫자를 예측해야하면 분류

##### 분류 모델에서 Accuracy가 높다고 해서 항상 좋은 모델이라고 할 수 없는 이유는 무엇인가?
###### Accuracy는 전체데이터중 모델이 맞춘 데이터의 비율. 즉 이상데이터의 유무와 관계없이 Accuracy가 계산되므로 높을수록 좋은모델이라고 할수없음.

##### 데이터를 StandardScaler 등의 방법으로 스케일링하는 이유는 무엇인가? 모든 머신러닝 모델에서 스케일링이 똑같이 중요한지도 함께 설명해보자.
###### 스케일링을 하면 각 특성이 비슷한 기준에서 학습될수있도록 만들어준다. 랜덤포레스트나 라이트쥐비엠같은 트리기반 모델은 데이터를 어떤 기준으로 나눌지를 보기때문에 일반적으로 스케일링의 필요성이 크지않음 (사실 이해못했습니다.) 

##### 데이터 누수(Data Leakage)란 무엇이며, 데이터 누수가 발생하면 Validation 성능이 실제보다 높게 나올 수 있는 이유는 무엇인가? 누수가 발생할 수 있는 상황도 한 가지 예를 들어보자.
###### 데이터 누수는 실제 예측해야하는 정보가 Train데이터에 들어가서 Validation성능이 기존보다 비정상적으로 높게 나오는 현상. Train과 Validation 데이터를 나누기전에 전체 데이터에 결측치처리를 하는 상황. 원래는 Train데이터를 기준으로 전처리를 학습하고 그걸 validation이나 Test데이터에 적용해야함.

##### 파라미터(Parameter)와 하이퍼파라미터(Hyperparameter)는 어떻게 다른가? 하이퍼파라미터 값을 바꾸면 모델의 성능이 달라질 수 있는 이유도 설명해보자.
###### 파라미터는 모델이 스스로 결정하는 값. 하이퍼는 사용자가 정해주는 값. 하이퍼파라미터를 크게 설정하면 Train데이터에 너무 맞춰지는 과적합이 발생하거나 너무 얕게 설정하면 데이터를 충분히 학습할수없는 등의 성능이 달라질수있음.

##### Random Forest와 Gradient Boosting(XGBoost, LightGBM 등)은 모두 여러 Decision Tree를 사용하는데, 트리를 만드는 방식에는 어떤 차이가 있는가?
###### Random Forest는 트리를 독립적으로 만들고 예측해서 결과를 합치는 방식. Gradient Boosting은 앞에서 만든 트리의오류를 다음트리가 보완하는 방식. 
 
##### GridSearchCV와 같은 하이퍼파라미터 탐색 방법을 사용하는 이유는 무엇인가? 가능한 값을 무조건 많이 탐색하면 항상 더 좋은 모델을 찾을 수 있는지도 생각해보자.
###### 탐색할 값이 많아질수록 계산 시간이 오래걸리고, Validation데이터에너무 맞는 파라미터를 선택할수도 있게되므로, 적절한 범위를 정하고 일반화성능이 좋은 조합을 찾는것이 중요. 
  
##### Train 또는 Validation에서는 성능이 좋았지만 실제 Test 데이터에서 성능이 크게 떨어졌다면 어떤 원인을 의심할 수 있는가?
###### 과적합과 데이터 누수를 의심해볼수있음. 모델이 Train을 너무 자세하게 학습하면 새 데이터에는 성능이 떨어짐. 또 Train이나 Validation을 만드는 과정에서 Test데이터의 정보가 들어갔다면 Validation 성능이 원래보다 더 높게 나올수있음.
