# 캐글 과제2

## 1. 회귀와 분류 차이

회귀는 연속적인 숫자값을 예측하는 문제임.  
예: 집값, 보험료 예측

분류는 정해진 클래스 중 하나를 예측하는 문제임.  
예: 생존 여부, 스팸 여부

숫자 자체를 예측하면 회귀, 종류를 예측하면 분류라고 보면 됨.

---

## 2. Accuracy가 항상 좋은 지표는 아닌 이유

Accuracy는 전체 중 맞춘 비율임.

하지만 한쪽 클래스가 너무 많으면 Accuracy가 높아도 좋은 모델이 아닐 수 있음.

예를 들어 정상 95개, 이상 5개일 때 전부 정상이라고 예측해도 Accuracy는 95%임.  
근데 이상 데이터는 하나도 못 찾은 거라 실제로는 좋다고 보기 어려움.

이럴 때 Precision, Recall, F1-score도 같이 봐야 함.

---

## 3. 스케일링하는 이유

특성마다 값의 크기 차이가 너무 크면 값이 큰 특성이 더 큰 영향을 줄 수 있음.

예를 들어 나이는 20~60 정도인데 연봉은 수천만 단위면 차이가 큼.

그래서 StandardScaler 같은 걸로 값의 범위를 비슷하게 맞춰줌.

다만 모든 모델에 꼭 필요한 건 아님.  
KNN, SVM, 선형 모델은 영향을 많이 받고, Random Forest 같은 트리 모델은 비교적 영향이 적음.

---

## 4. 데이터 누수

데이터 누수는 모델이 학습할 때 원래 알면 안 되는 Validation이나 Test 데이터 정보를 미리 사용하는 경우임.

예를 들어 전체 데이터 평균으로 결측치를 채운 뒤 Train/Validation을 나누면 Validation 정보도 학습에 들어갈 수 있음.

그러면 Validation 성능이 실제보다 높게 나올 수 있음.

그래서 전처리는 Train 데이터 기준으로 학습하고 Validation/Test에 적용해야 함.

---

## 5. 파라미터와 하이퍼파라미터 차이

파라미터는 모델이 학습하면서 직접 구하는 값임.

예: 선형회귀의 가중치, 절편

하이퍼파라미터는 학습 전에 사람이 정하는 값임.

예: Random Forest의 `n_estimators`, `max_depth`

하이퍼파라미터 값에 따라 모델 성능이나 과적합 정도가 달라질 수 있음.

---

## 6. Random Forest와 Gradient Boosting 차이

둘 다 여러 Decision Tree를 사용하는 모델임.

Random Forest는 여러 트리를 각각 따로 학습한 뒤 결과를 합침.

Gradient Boosting은 앞의 트리가 틀린 부분을 다음 트리가 보완하면서 순서대로 학습함.

즉 Random Forest는 여러 트리를 독립적으로 만들고, Gradient Boosting은 이전 오차를 계속 보완하는 방식임.

---

## 7. GridSearchCV를 사용하는 이유

하이퍼파라미터 값에 따라 성능이 달라질 수 있어서 좋은 조합을 찾기 위해 사용함.

GridSearchCV는 여러 하이퍼파라미터 조합을 자동으로 비교하고 교차검증해서 좋은 조합을 찾아줌.

값을 너무 많이 넣으면 시간이 오래 걸리기 때문에 적당한 범위로 탐색하는 게 좋음.

---

## 8. Train/Validation 성능은 좋은데 Test에서 떨어지는 이유

가장 먼저 과적합을 의심할 수 있음.

Train 데이터에 너무 맞게 학습되면 새로운 Test 데이터에서는 성능이 떨어질 수 있음.

Validation 데이터를 보면서 계속 모델을 수정한 경우 Validation에도 과하게 맞춰질 수 있음.

데이터 누수가 있거나 Train과 Test 데이터 분포가 다른 경우에도 성능이 떨어질 수 있음.

그래서 Train/Validation/Test를 제대로 분리하고 과적합이나 데이터 누수가 없는지 확인해야 함.
