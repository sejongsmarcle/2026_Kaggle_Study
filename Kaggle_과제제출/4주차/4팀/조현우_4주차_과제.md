# 과제 2
1. **회귀(Regression)와 분류(Classification)는 무엇이 다르며, 어떤 문제를 풀고 있는지는 무엇을 보고 판단할 수 있는가?**
	- 회귀는 연속적인 값에 대한 예측, 분류는 이산적인 값에 대한 예측이다.
2. **분류 모델에서 Accuracy가 높다고 해서 항상 좋은 모델이라고 할 수 없는 이유는 무엇인가?** 데이터의 한쪽 클래스가 훨씬 많은 경우를 예로 들어 설명해보자. 
	- 데이터가 모든 클래스가 균등하게 나뉘어져있다는 보장은 없다. 따라서 기존 테스트 데이터셋에서 정확도가 높다고 한들 무조건 좋은 모델이라고 할 순 없다.
3. **데이터를 StandardScaler 등의 방법으로 스케일링하는 이유는 무엇인가?** 모든 머신러닝 모델에서 스케일링이 똑같이 중요한지도 함께 설명해보자. 
	- 어떤 연속적인 값이 있는 데이터셋이 있다고 하자. 그리고 그게 나이와 연봉의 상관관계를 보는 거라고 치만, 60세란 나이와 200,000,000이라는 연봉은 숫자 차이가 굉장히 크기 때문에 모델은 연봉이란 특성을 크게 받아들일 수 있다. 따라서 스케일링을 통해 정규화가 공평하게 적용되게 하기 위해서다. 특히 KNN, K-means, 와 같이 특정 점부터 벡터 거리를 통해 그룹화하는 경우엔 더 중요.
4. **데이터 누수(Data Leakage)란 무엇이며, 데이터 누수가 발생하면 Validation 성능이 실제보다 높게 나올 수 있는 이유는 무엇인가?** 누수가 발생할 수 있는 상황도 한 가지 예를 들어보자. 
	- 데이터 누수는 학습될 때 들어가면 안 되는 정보가 모델에게 들어가는 경우다. test / valid set 같은 게 예시다. 이런 경우 평가하는 과정을 이미 배운 모델이 되어 평가가 잘 진행된다고 할 수 없다.
5. **파라미터(Parameter)와 하이퍼파라미터(Hyperparameter)는 어떻게 다른가?** 하이퍼파라미터 값을 바꾸면 모델의 성능이 달라질 수 있는 이유도 설명해보자. 
	- 파라미터는 기계가 학습을 통해서 가장 적합한 값을 찾아가는 것 (가중치 같은) 하이퍼파라미터는 사람이 직접 조정해주는 값이다. learning rate, epoch, num worker 등 학습과 관련된 하이퍼파라미터를 어느 정도로 조정하느냐에 따라서 과적합이 걸릴 수도, 혹은 적절한 값을 통해 좋은 성능을 얻어낼 수도 있다.
6. **Random Forest와 Gradient Boosting(XGBoost, LightGBM 등)은 모두 여러 Decision Tree를 사용하는데, 트리를 만드는 방식에는 어떤 차이가 있는가?** 
	- Random Forest는 말 그대로 랜덤하게 트리를 독립적으로 만드는 형태이고, Gradient Boosting은 이전에 단계에 있는 트리가 틀린 부분에 대한 보정을 하기 위함이 있기 때문에 순서가 영향을 준다. 
7. **GridSearchCV와 같은 하이퍼파라미터 탐색 방법을 사용하는 이유는 무엇인가?** 가능한 값을 무조건 많이 탐색하면 항상 더 좋은 모델을 찾을 수 있는지도 생각해보자. 
	- 하이퍼파라미터는 사람이 임의로, 휴리스틱하게 결정하는 값이기 때문이다. 이걸 매번 하나하나 찾을 수 없기 때문도 있다. 더 나아가서는 이 하이퍼파라미터들은 모델이 학습해가며 바꾸지 않기 때문에 이 값들을 비교하여 성능이 좋은 조합을 찾기 위함도 있다. 가능한 값을 무조건 많이 탐색한다면 오히려 반대로 검증 데이터셋에 대한 과적합이 일어날 수 있다.
8. **Train 또는 Validation에서는 성능이 좋았지만 실제 Test 데이터에서 성능이 크게 떨어졌다면 어떤 원인을 의심할 수 있는가?** 과적합, 데이터 누수, Train/Test 데이터 차이 등의 개념을 활용하여 설명해보자
	1. 에포크 수와 같은 다양한 조건에 의해서 과적합이 발생해 train / valid set에 대해서만 학습이 되고 일반화가 되지 않았다.
	2. 데이터 누수가 발생해 validation set을 모델이 학습해 검증 과정에서도 성능이 좋았지만, 실제 test 데이터셋에서는 떨어졌다.
