1. 결측치(missing value)란 무엇이고, 왜 그냥 두면 안 되는가?
  - 결축치는 데이터 수집 과정에서 누락되어 값이 비어있는 상태를 의미한다. 데이터 학습시에 데이터에 빈칸이 있으면 연산 에러가 발생하여 모델 학습 자체가 불가능해 질 수 있으므로 모델 학습 전에 처리해두어야 한다.
2. 훈련(train) 데이터와 테스트(test) 데이터를 나누는 이유는 무엇인가?
  - 모델이 데이터의 패턴을 학습한 것인지, 단순히 정답을 암기한 것인기 확인하는 목적으로 모델이 새로운 데이터에도 제대로 작동하는지 평가하기 위해서이다.
3. 과적합(overfitting)이 무엇인지, 왜 안 좋은지 예를 들어 설명해보라.
  - 모델이 훈련 데이터에 너무 과도하게 맞춰져서 훈련 데이터의 사소한 노이즈나 예외 상황까지 전부 정답의 규칙으로 착각해 외워버린 상태를 의미한다.
    예를 들어 타이타닉 모델이 '티켓 번호 끝자리가 7이면 생존한다'라는 식의 우연한 패턴까지 학습해버리는 경우가 있다.
4. 범주형 변수(categorical variable)를 숫자로 바꿔야 하는 이유는 무엇인가?
  - 알고리즘은 텍스트의 의미를 이해하지 못하고 숫자를 기반으로 사칙연산을 수행하기 때문.
5. 특성 엔지니어링(Feature Engineering)이 무엇이며, 왜 원본 데이터를 그대로 쓰지 않고 새로운 변수를 만드는가?
  - 가공 되기 전 데이터에는 필요한 데이터가 파편화되어있기 때문에, 원본 데이터를 조합, 변형하여 모델이 더 쉽게 정답 패턴을 찾을 수 있도록 처리하는방법이다.
    새로운 변수를 사용하여 머신러닝 모델이 정답 패턴을 더 쉽게 파악할 수 있도록 한다.
6. EDA(탐색적 데이터 분석)를 모델링 전에 먼저 하는 이유는 무엇인가?
  - 데이터의 결측치, 이상치, 변수 간의 관계 등을 미리 시각적으로 파악해야 모델링의 올바른 전략을 세울 수 있기 때문이다.
7. 교차검증(Cross Validation)이 한 번의 검증(홀드아웃)보다 신뢰할 수 있는 이유는 무엇인가?
  - 데이터를 여러 조각으로 나누어 훈련과 테스트 역할을 번갈아 가며 여러 번 평가하므로, 특정 데이터 배정에 따른 운이나 편향을 방지한다.
8. Feature Importance(특성 중요도)를 확인하면 실제로 어떤 도움이 되는가?
  - 모델이 예측을 내릴 떄 어떤 데이터를 가장 중점적으로 보는지 직관적으로 파악 할 수 있다.
