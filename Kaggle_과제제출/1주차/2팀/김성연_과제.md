### 📝 개념 설명 문제 (자신만의 해설 작성)

1. 결측치(missing value)란 무엇이고, 왜 그냥 두면 안 되는가?
- 비어있는 데이터이고 머신러닝에서 인풋값에 NAN이 있으면 출력을 못 낼 수 있음
- 
  
2. **훈련(train) 데이터와 테스트(test) 데이터를 나누는 이유**는 무엇인가?
- 모델이 처음보는 데이터에서 얼마나 좋은 성능이 나오는지 확인하기 위해서

  
3. 과적합(overfitting)이 무엇인지, 왜 안 좋은지 예를 들어 설명해보라.
- 과적합은 모델이 특정 데이터에만 완벽히 적응하여 일반화를 하지 못한 상태로 범용적으로 좋은 모델을 만들지 못함
- 예시 : 진짜 특이한 고양이 사진을 데이터로 학습하면 일반적인 고양이를 봤을때 고양이로 판별 못할 수도 있음

  
4. **범주형 변수(categorical variable)를 숫자로 바꿔야 하는 이유**는 무엇인가? (모델이 문자를 이해하지 못하는 이유)
- 인공지능은 숫자형 데이터를 처리할 수 있기 때문이다. 대부분의 ML/DL의 연산은 수치를 기반으로 작동하고 있어서 숫자로 변환해줘야 함

  
5. 특성 엔지니어링(Feature Engineering)이 무엇이며, 왜 원본 데이터를 그대로 쓰지 않고 새로운 변수를 만드는가?
-  특성 엔지니어링이란 기존 데이터를 이용해 새로운 데이터를 만드는 것이고 더욱 의미있는 인풋을 만들 수 있기 때문이다
-  예를 들어 타이타닉 생존자 예측에서 형제자매데이터와 부모자녀 데이터를 합쳐 가족데이터를 만들어 가족의 인원수가 생존에 어떤 영향을 주는지 확인함
  
  
6. EDA(탐색적 데이터 분석)를 모델링 전에 먼저 하는 이유는 무엇인가?
 - 탐색적 데이터 분석을 통해 데이터의 특성을 파악할 수 있고 어떤 데이터가 연관성이 있는지를 일단 우리가 눈으로 보고 확인을 해 가설을 세울 수 있고 모델이 내린 결론에 의미를 부여할 수 있음
   
   
7. 교차검증(Cross Validation)이 한 번의 검증(홀드아웃)보다 신뢰할 수 있는 이유는 무엇인가?
 - 교차검증은 훈련데이터에서 일부분을 테스트데이터로 사용하는 것으로 그 일부를 계속 바꿈으로써 더욱 다양하게 테스트 해볼 수 있어 더욱 신뢰할 수 있는 점수를 얻을 수 있음
   
   
8. Feature Importance(특성 중요도)를 확인하면 실제로 어떤 도움이 되는가?
- 특성 중요도는 어떤 특성이 모델이 예측을 하는데 중요한가를 보여주는 지표이고 블랙박스 같은 머신러닝/딥러닝의 설명가능성을 높여주기 때문에 도움이 된다
