1.결측치(missing value)란 무엇이고, 왜 그냥 두면 안되는가?
   결측치(Missing Value)란 데이터에서 값이 비어 있거나 기록되지 않은 것을 말한다. 그냥 두면 통계 분석이나 머신러닝 모델의 계산에 오류가 생기거나 결과의 정확도가 떨어질 수 있기 때문에 적절히 처리해야 한다. 
  결측치 처리 방법은 대표적으로
  삭제: 결측치가 있는 행이나 열을 제거
  평균/중앙값 대체: 숫자 데이터의 빈 값을 평균이나 중앙값으로 채움
  최빈값 대체: 범주형 데이터의 빈 값을 가장 많이 나온 값으로 채움
  예측하여 대체: 다른 데이터를 이용해 결측값을 추정함
  등 의 방법이 있다 

2.훈련(train) 데이터와 테스트(test) 데이터를 나누는 이유는 무엇인가?
  훈련 데이터로 모델을 학습하고, 테스트 데이터로 학습하지 않은 새로운 데이터에서도 잘 작동하는지 성능을 평가하기 위해 나눈다.

3.과적합(overfitting)이 무엇인지, 왜 안 좋은지 예를 들어 설명해보라
  과적합(Overfitting은 모델이 훈련 데이터의 특징이나 오류까지 지나치게 외워서, 새로운 데이터에서는 성능이 떨어지는 현상이다.
  예) 시험 문제와 답을 전부 외운 학생이 비슷한 문제는 잘 풀지만, 처음 보는 문제는 잘 못 푸는 것과 같다.

4.범주형 변수(categorical variable)를 숫자로 바꿔야 하는 이유는 무엇인가? (모델이 문자를 이해하지 못하는 이유)
  모델이 파라미터를 조정하며 학습하기 위해선 문자로 된 변수를 숫자로 바꿔 수학적 연산을 진행해야한다

5.특성 엔지니어링(Feature Engineering)이 무엇이며, 왜 원본 데이터를 그대로 쓰지 않고 새로운 변수를 만드는가?
  특성 엔지니어링(Feature Engineering)은 원본 데이터에서 모델 학습에 도움이 되도록 새로운 특성을 만들어내는 과정이다.

 원본 데이터만 사용하는 것보다 데이터의 중요한 특징을 더 잘 표현하여 모델의 예측 성능을 높일 수 있기 때문이다.
 단 특성을 과도하게 만들어내면 과대적합에 걸릴수도 있다

6.EDA는 데이터를 미리 살펴보고 결측치, 이상치, 변수 간 관계 등을 파악하기 위해 모델링 전에 한다.

이를 통해 데이터 문제를 발견하고 적절한 전처리와 특성 선택을 할 수 있어 모델의 성능을 높일 수 있다.

7.교차검증(Cross Validation)이 한 번의 검증(홀드아웃)보다 신뢰할 수 있는 이유는 무엇인가?  
교차검증은 데이터를 여러 번 나누어 검증하고 결과를 평균내기 때문에, 한 번만 나누는 홀드아웃보다 특정 데이터 분할에 따른 운에 영향을 덜 받아 성능을 더 안정적으로 평가할 수 있다.

8. Feature Importance(특성 중요도)를 확인하면 실제로 어떤 도움이 되는가?
  중요한 변수가 무엇인지 파악하고 중요도가 낮은 변수는 다른 변수로 대체하거나 삭제할 수 있다. 
  이로 인해 모델의 성능을 더욱 개선할 수 있다.
